Hubungkan web presensi ini dengan Google Apps Script Web App sebagai basis data server utama.

Panduan Proteksi Keamanan Data saat Hosting GitHub Pages

  • API Token Header Authentication: Pastikan Google Apps Script Anda mengecek API Security Token pada header/payload request agar mencegah manipulasi data dari pihak luar.
  • Cross-Origin Resource Sharing (CORS): Atur header respon Apps Script hanya mengizinkan domain GitHub Pages sekolah Anda (misal: https://sekolah.github.io).
  • Validasi Koordinat GPS di Server-Side: Pengecekan toleransi jarak GPS dilakukan juga di server (Apps Script) untuk mencegah modifikasi script frontend oleh pengguna (Anti-Titip Absen).
  • Enkripsi Payload Presensi: Kode QR siswa dikodekan menggunakan Hash/Token terenkripsi (bukan NISN mentah) untuk mencegah pemalsuan cetak barcode oleh pihak tak berwenang.
